A program that writes one funny one-line resignation letter to `/output/entry.txt` — a single line, 120 characters, from an office worker who has decided to quit before the office plant claims another victim. No input, no network, no randomness: every run writes the exact same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
